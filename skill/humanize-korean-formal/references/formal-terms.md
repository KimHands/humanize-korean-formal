# 공식 용어 검토 — 판정 기준과 사례

SKILL.md 「Phase 3: 공식 용어 검토」가 이 파일을 읽는다. 후보 표를 만들기 전에 끝까지 읽는다.

## 분류

| 분류 | 대상 | 기본 판정 |
|---|---|---|
| **A 비유** | 글자 그대로의 뜻이 아니라 이미지로 말하는 표현 | 권장 |
| **B 1인칭·구어** | 뜻은 글자 그대로지만 말투가 사적이거나 구어인 표현 | 권장 |
| **C 소제목** | 문서 제목을 뺀 모든 소제목·표/그림 캡션 속 비유·구어·의문형·대조형 | 선택 |
| **D 제목** | 문서 제목(표지 제목·과제명) | 선택 |
| **E 유지** | 그 분야의 정의된 용어를 정의대로 쓴 것 | 바꾸지 않음 |

A와 B가 헷갈리면: 문장을 글자 그대로 읽었을 때 사실과 다르면 A(예: "위에서 끊는다" — 실제로 위에서 자르는 게 아니다), 사실은 맞는데 말투가 문제면 B("쓰면 된다").

## 훑는 순서 — 빠뜨리지 않기 위한 체크리스트

1. **문서 제목** 1개 → D 후보인지 본다.
2. **소제목 전부**를 위에서부터 하나씩 → C. 특히 의문형("왜 ~인가"), 대조형("~가 아니라 ~"), 구어("~를 좌표로"), 캡션.
3. **본문 문장**마다 A 표지를 찾는다: 동작 동사를 추상 대상에 쓴 것(뭉갠다·묻힌다·얹다·끊다·걸러지다·잡히다·접히다·붙다), 신체·사물 비유(꼬리·뼈대·손), 감정·의인화(유혹·정직하다·품다).
4. **본문 문장**마다 B 표지를 찾는다:
   - 1인칭: 우리·저희·나·내가·우리가 가진
   - 구어 종결·조동: ~면 된다, ~거든, ~잖아, ~하는 셈이다
   - **문장 첫머리 구어 접속사**: 그런데·근데·그래서·그러니까 → 그러나/한편/따라서 (문맥에 따라)
   - 구어 부사: 싹·딱·좀·되게·그냥·확·쭉
   - 구어 반문: "~ 아니냐", "~ 말이 되나"
5. 같은 표현이 여러 곳에 나오면 **위치를 모두** 적는다(한 행에 "전체 N곳" 또는 위치 나열).

## E 유지 판정 — 좁게

E는 다음 **둘 다** 성립할 때만:
1. 그 분야 교과서·공공 보고서가 정의된 용어로 쓰는 말이다.
2. 이 문장이 **그 정의대로** 쓰고 있다.

한쪽이라도 확신이 없으면 **A로 올리고 제안 칸에 "(E 가능: 이유)"를 덧붙인다.** 판단은 사용자가 한다.
E로 잘못 두면 후보가 표에서 사라져 사용자가 고를 기회를 잃고, A로 잘못 올리면 표에 한 줄이 늘 뿐이다.

| 표현 | 판정 | 이유 |
|---|---|---|
| 공간 **해상도** | E | GIS 용어(집계 단위의 세밀도)를 그 뜻으로 씀 |
| **강건**(성) | E | 통계 용어 robustness |
| **고립** 지점 | E | 공간통계에서 이웃이 없는 지점. 실제로 이웃이 없는 지점에만 씀 |
| **다만** | E | 공문서에서도 쓰는 한정 접속어 |
| 해라체 문장 끝 **-다** | E | 문체. 바꾸지 않는다 |
| 분포의 **꼬리** | **A** | "꼬리 분포"는 통계 용어지만 여기서는 "값이 큰 쪽 사례들"이라는 느슨한 뜻 → 상위 구간 |
| 자기충족적 | A | 뜻을 풀어 "순환 구조"로 |

## 후보 표 형식

번호는 A부터 D까지 **이어서** 매긴다(사용자가 번호로 고른다). 파일에도 같은 내용을 저장한다.

```markdown
## A. 비유 표현 — 권장
| # | 위치 | 현재 | 제안 |
|---:|---|---|---|
| 1 | 배경 (1) | 노선 평균은 정류장 간 차이를 하나의 숫자로 **뭉갠다** | 노선 평균은 정류장 간 차이를 하나의 값으로 **평균화한다** |

## B. 1인칭·구어 — 권장
| 2 | 방법론 (6) | **우리** 데이터가 … | **보유** 데이터가 … |

## C. 소제목 — 선택
| # | 현재 | 제안 |

## D. 제목 — 선택
| # | 현재 | 제안 |
(바꿀 때의 득실 한 줄 — 예: 지금 제목은 문제를 한눈에 보여 주지만 공식성이 낮다)

## E. 유지 — 학술·기술 용어
| 표현 | 유지 이유 |
```

- **위치**: 소제목 번호·절 이름 등 원문에서 찾을 수 있는 이름. 줄 번호보다 절 이름을 우선한다.
- **현재/제안**: 바뀌는 말을 **굵게**. 앞뒤 몇 어절을 붙여 문맥이 보이게 한다.
- 제안은 한 가지로 낸다. 문맥에 따라 둘이면 "그러나 또는 한편 (문맥에 따라)".
- 표 아래에 선택 방법을 적는다: "권장만" = A·B / "권장+소제목" = A·B·C / "전부" / 번호 나열.

## 제안을 만들 때 지킬 것

- **숫자·고유명사·인용·주장은 그대로.** 용어만 바꾼다. 제안문에 원문에 없던 수치·근거·방법(예: "통합", "보정")을 넣지 않는다.
- 따옴표 안 문장은 후보로 올리지 않는다. 직접 인용이 아니라 글쓴이가 지어낸 가상의 반론처럼 보여도 바꾸지 말고, 필요하면 표 아래에 "따옴표 안이라 제외"로 적어 사용자에게 알린다.
- **문장 끝은 원문 문체를 따른다.** 해라체면 해라체("~다"), 합쇼체면 합쇼체.
- **숫자·영문 토큰의 등장 순서를 바꾸지 않는다.** 불변 검사가 순서까지 본다("A가 아니라 B" → "B(A …)"처럼 뒤집지 말고 "A 대신 B").
- 문장을 나누거나 합치지 않는다. 문장 수와 줄바꿈이 바뀌면 검사에 걸린다.
- 공식 용어로 바꾸면서 뜻이 넓어지거나 좁아지면 제안 칸 끝에 괄호로 적는다("(뜻 확인 필요: 상위 N개만 남긴다는 뜻인지)").
- 한 표현이 문서의 다른 곳(표·그림 캡션, 목차, 본문에서 소제목을 부르는 곳)에 **다시 나오면** 그 위치도 함께 적는다 — 적용할 때 같이 바꿔야 한다.

## 예시 (가상의 대학 셔틀버스 이용 분석 보고서 — 판정 결과: A·B·C 적용, D 보류)

| 분류 | 현재 → 제안 |
|---|---|
| A | 하나의 숫자로 **뭉갠다** → 하나의 값으로 **평균화한다** |
| A | 혼잡 시간대가 일 평균에 **묻힌다** → 일 평균에서 **식별되지 않는다** |
| A | 이 분석은 하나를 **겨냥한다** → 이 분석의 목적은 다음 한 가지다 |
| A | 데이터가 없는 모형을 **이름값으로 얹으면** → 데이터 요건을 충족하지 못하는 모형을 **적용하면** |
| A | 3단계 — **되먹임** → 3단계 — **환류** |
| A | 예산이 제한되면 **위에서 끊는다** → **상위 순위부터 적용한다** |
| A | 노선 기준으로는 **걸러지지 않는** 정류장 → **포착되지 않는** 정류장 |
| A | 야간 운행 기록이 **통째로 빠져** 있다 → **모두 누락돼** 있다 |
| A | **한 번 쓰고 버리는** 목록 → **일회성** 목록 |
| B | **우리가 가진 것** → **보유 데이터** |
| B | **우리가 지어낸** 점검 주기 → **임의로 정한** 점검 주기 |
| B | 보완 자료로 **쓰면 된다** → **활용할 수 있다** |
| B | 문장 첫머리 **그런데**(전체 5곳) → **그러나** 또는 **한편** |
| C | (3) **왜 지금 필요한가** → (3) **시의성** |
| C | (1) 분석 단위 — 노선 12개**가 아니라** 정류장 86곳 → (1) 분석 단위 — 노선 12개 **대신** 정류장 86곳 |
| C | (2) 지오코딩 — **주소를 좌표로** → (2) 지오코딩(**주소의 좌표 변환**) |
| D | **학생은 늘었는데 버스는 그대로인 곳** → **수요 대비 셔틀버스 공급 부족 정류장 식별** (사용자가 보류 — 지금 제목이 문제를 더 잘 보여 준다는 판단) |
